`neuro-js` is published to npm. It ships ESM, CJS, an IIFE bundle for
direct script tags, and full TypeScript types.

<InstallTabs />

## Peer requirements

| Runtime         | Minimum |
| --------------- | ------- |
| Node            | 18.18   |
| Bun             | 1.0     |
| Modern browsers | ES2022  |

The `openai` SDK is a runtime dependency. It is not bundled into the
ESM/CJS outputs (treeshaking-friendly). It is inlined into the IIFE
bundle so a single script tag works on a static page.

## CDN (no build tool)

```html
<script src="https://unpkg.com/neuro-js/dist/neuro-js.iife.js"></script>
<script>
  NeuroJS.configureClient({
    tokenProvider: () => fetch('/api/neuro-token').then((r) => r.text()),
  });
  NeuroJS.neuro.array
    .map({ array: ['a', 'b'], callbackfn: (s) => s, prompt: 'uppercase each' })
    .then(console.log);
</script>
```

## Verify your install

```ts
import { configureClient, neuro } from 'neuro-js';

configureClient({ apiKey: process.env.OPENAI_API_KEY });
console.log(await neuro.math.random({}));
```
