## What support funds

| Bucket                    | What it covers                                                                                                                                                    |
| ------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Domain & hosting**      | `neuro-ts.dev` registration, edge hosting for the documentation site.                                                                                             |
| **OpenAI testing budget** | Running real end-to-end requests across the 600+ wrapped methods on every release to verify prompts behave.                                                       |
| **Generator maintenance** | Keeping the Compiler API generator in step with new TypeScript releases. Each TS lib bump can shift signatures (`Uint8Array<TArrayBuffer>` was a recent example). |
| **Reference proxy**       | Maintaining the `neuro-ts-proxy` reference implementation across Node, Bun, Deno, Cloudflare Workers, and Vercel Edge.                                            |
| **Docs & examples**       | Writing more guides, recording short video walkthroughs, building richer examples.                                                                                |

## Other ways to help

- **Star the repository.** Visibility helps more than donations. [github.com/utajum/neuro-ts](https://github.com/utajum/neuro-ts).
- **Open issues.** Bug reports, gaps in the catalog, prompt improvements.
- **Submit pull requests.** The generator is the single biggest leverage point; improvements compound across 600+ methods.
- **Tell a friend.** A short blog post or a tweet still moves the needle for niche dev tools.

## Sponsorship

Larger sponsorships and consulting on integrations are welcome. Open an
